One-time setup: register a free app in Azure (5 minutes)
  1. Go to Azure portal → App registrations and sign in with your Outlook (university) account. Click New registration.
  2. Name: Job Autopilot. Supported account types: Accounts in this organizational directory only. Leave Redirect URI empty. Click Register.
  3. Open Authentication → Advanced settings → set Allow public client flows to Yes → Save.
  4. Open API permissions → Add a permission → Microsoft Graph → Delegated → check Mail.Read → Add. (User.Read is already there.)
  5. Copy the Application (client) ID from Overview, paste it above with your Outlook email, and click Sign in. Approve the read-only mail permission when Microsoft asks.

If Azure says you can't register apps, or sign-in says "Need admin approval," your organization restricts third-party apps. Then forward application emails to your Gmail with an Outlook rule, and the Gmail connection covers them.
